# 账户会话分析契约

覆盖为账户会话控制新增的两条面向用户流程：在浏览器中批准命令行客户端（`/login/device`），以及从账户菜单查看或结束登录会话。

这两条都是异步工作流，单一信号无法描述结果：一个被打开后放弃的提示，和被拒绝的提示看起来完全一样，除非终态被分别记录。

本文是 [`account-session-analytics.md`](account-session-analytics.md) 的中文译本。代理、工具链和校验仍以英文版为准；若两份文档不一致，以英文版为准。

### 设备授权

- 业务问题：当有人被要求授权命令行客户端时，他们完成的频率是多少、拒绝的频率是多少、提示无人应答的频率又是多少？如果拒绝率不是接近零，就意味着人们看到了并非自己发起的请求。
- 指标定义：分子是批准事件（`device_auth_approved`）；分母是同一自然周内的提示曝光事件（`device_auth_prompt_shown`），并按共享的 `device_os` 和 `from_link` 字段分组。放弃率是残差 `1 - (approved + denied) / shown`，它之所以有意义，只是因为曝光被单独计数。没有请求标识符时，这个计算是聚合的，不能作为行级 join 呈现。
- 事件名：`device_auth_prompt_shown`、`device_auth_approved`、`device_auth_denied`。
- 行动者与表面：已登录用户，且仅在 `/login/device` 页面。
- 触发：曝光在每次解析出的待处理请求上从 post-commit effect 触发一次。结果事件只在后端确认决定后发出，绝不能在点击本身时发出。
- 人群：已登录用户。未登录访客会先被重定向去登录，不发出任何事件。
- 计数单位：一条待处理授权请求。
- 去重：以 ref 中持有的配对码为键，因此重渲染和第二次 effect 不会放大分母。范围是一次已挂载的页面。
- 关联：无。配对码是有效十分钟的活凭据，被有意从每个 payload 中省略，因此这些事件无法 join 到特定请求。
- 消费者：尚无。流程上线后，拒绝率是最值得关注的信号。
- 兼容性：增量；三个新名称，且 `from_link` 包含在全部三个事件的完整 payload 中。
- 校验：`src/web/src/app/login/device/page.test.tsx` 断言曝光恰好触发一次、配对码不进入 payload、从链接打开和手工输入的结果保留与其曝光相同的 `from_link` 维度、结果在确认时发出，以及失败的决定不发出结果事件。

| 字段 | 类型 | 允许值 | 基数 | 隐私类别 | 为何必需 |
| ----------- | ------- | -------------------------------------------------------------------------------- | ----------- | ------------- | --------------------------------------------------------------- |
| `device_os` | string | `android`、`chromeos`、`ios`、`linux`、`macos`、`other`、`unknown` 或 `windows` | 低 | 非个人 | 判断拒绝是否集中在某一个平台 |
| `from_link` | boolean | true/false | 低 | 非个人 | 区分从链接打开的提示和手工输入的配对码 |

### 会话管理

- 业务问题：人们到底会不会使用会话控制？如果会，他们是结束自己识别出的那一条错误会话，还是清空全部？第二种情况意味着他们分不清哪一条会话是可疑的。
- 指标定义：分子是一个自然月内发出任意撤销事件的去重用户数；分母是同一月内发出 `session_list_opened` 的去重用户数。把单条撤销和批量撤销的拆分，按撤销用户的占比跟踪，而不是按事件数。
- 事件名：`session_list_opened`、`session_revoked`、`session_revoked_others`。
- 行动者与表面：已登录用户，来自 learner 和 creator 表面上的账户菜单。表面会带在打开事件上。
- 触发：打开事件在菜单项被激活时发出；撤销事件只在后端确认后发出，因此失败的撤销不发出任何事件。
- 人群：已登录用户。未登录时该入口是隐藏的。
- 计数单位：采纳指标按用户计；单条 vs 批量拆分按事件计。
- 去重：会话内无去重。重新打开对话框是一次真实的重复动作，应再次计数。
- 关联：无。会话标识符命名的是活凭据的一行，被有意从每个 payload 中省略。
- 消费者：尚无。
- 兼容性：增量；三个新名称。
- 校验：`src/web/src/components/Settings/SessionManagerModal.test.tsx` 断言结果只在已确认的撤销时发出、失败的撤销不发出任何事件，以及没有任何会话标识符进入 payload。

| 字段 | 类型 | 允许值 | 基数 | 隐私类别 | 为何必需 |
| --------- | ------ | ------------------ | ----------- | ------------- | ------------------------------------------------------------ |
| `surface` | string | `learner`、`admin` | 低 | 非个人 | 显示人们从哪个表面管理会话 |
| `source` | string | `web`、`cli`、`` | 低 | 非个人 | 区分结束浏览器会话和结束 CLI 会话 |
